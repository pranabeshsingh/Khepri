# Pithon GitHub Actions CI & ARM64 E2E Test Suite Design

**Date:** 2026-10-11  
**Target Runner:** `ubuntu-24.04-arm` (GitHub ARM64 runner with ARM Neoverse / NEON acceleration)  
**Target Matrix:** Python 3.10, 3.11, 3.12 (x86_64 and ARM64)  
**Target Models:** SmolLM-135M-Instruct (~90 MB) & Qwen2.5-0.5B-Instruct (~350 MB)  

---

## 1. Objectives

1. Guarantee that every commit passes unit, security, and integration tests across supported Python versions.
2. Validate real ARM64 SIMD inference execution on native ARM runners (`ubuntu-24.04-arm`).
3. Verify live model behavior for:
   - Piped stdin log diagnostics (`pithon pipe`).
   - Server daemon streaming SSE and batch JSON (`pithon serve`).
   - RSS memory ceiling compliance (< 550 MB).

---

## 2. GitHub Actions Workflow Architecture (`.github/workflows/ci.yml`)

### Job 1: `unit-tests` (Cross-platform Matrix)
* **Triggers:** Push to `master`, PRs to `master`.
* **Runs On:** `ubuntu-latest` (x86_64) and `ubuntu-24.04-arm` (ARM64).
* **Python Matrix:** `["3.10", "3.11", "3.12"]`.
* **Steps:**
  1. Check out repository.
  2. Set up Python.
  3. Install dependencies (`pytest`).
  4. Run unit and security test suite (`pytest tests/test_*.py -m "not e2e"`).

### Job 2: `arm64-e2e-inference` (Live Model Runner)
* **Runs On:** `ubuntu-24.04-arm` (native ARM64).
* **Python Version:** `3.12`.
* **Steps:**
  1. Check out repository.
  2. Set up Python 3.12.
  3. Cache `./models/` directory using `actions/cache` with hash key on `scripts/download_model.sh`.
  4. Build and install `llama-cpp-python` with native ARM NEON SIMD enabled.
  5. Download test models (SmolLM-135M & Qwen2.5-0.5B) if not cached.
  6. Run comprehensive end-to-end suite (`pytest tests/test_e2e_real_model.py -v -s`).
  7. Run CLI sanity checks directly in bash:
     - `echo "panic: nil pointer" | pithon pipe --model models/smollm-135m-instruct-q4_k_m.gguf`
     - Background daemon launch and curl verification.

---

## 3. End-to-End Test Suite (`tests/test_e2e_real_model.py`)

### 3.1 Test Cases
1. **`test_e2e_smollm_pipe`**:
   - Ingests real Linux OOM / segmentation fault logs into `pithon pipe`.
   - Asserts non-empty diagnosis output generated by `SmolLM-135M`.
2. **`test_e2e_qwen_pipe_preset`**:
   - Ingests Nginx 502 Bad Gateway / upstream timeout logs.
   - Applies `--preset log-analyzer`.
   - Asserts generated response contains structured bullet points.
3. **`test_e2e_live_server_streaming`**:
   - Boots background daemon on dynamic test port.
   - Calls `/health` -> verifies HTTP 200 and model metadata.
   - Calls `/v1/chat/completions` with `stream: true`.
   - Verifies Server-Sent Events framing (`data: {"id":...}`) and closing `data: [DONE]`.
4. **`test_e2e_memory_ceiling`**:
   - Uses `psutil` or `resource.getrusage` to measure resident set size (RSS).
   - Confirms peak RAM consumption during 512-token generation stays under 550 MB.
